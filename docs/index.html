A fast desktop client for your Kafka clusters.

Browse topics, read the latest messages or tail new ones live, filter them with a small query language, and produce realistic test data. No server, no consumer groups, nothing to install besides the app.

Features

Everything you reach for when debugging a topic.

Clusters in folders

Group connections and tag each one DEV, TEST or PROD with a colour. Export and import them as JSON — passwords never included.

SASL, TLS & keychain

PLAINTEXT, SSL, SASL_PLAINTEXT and SASL_SSL with PLAIN or SCRAM. JKS, PKCS#12 or PEM stores. Secrets live in the OS keychain.

Latest messages

Opening a topic reads its newest messages across all partitions. Partitions are assigned directly: no consumer group, nothing committed.

Live tail

Watch new messages arrive, newest first, with a configurable buffer. Each partition gets its own colour.

Query language

Filter on JSON fields, arrays and nulls with and, or, not and contains. Plain text searches keys and values.

Text, JSON, XML, Hex

Inspect values, keys and headers in the format they are in. Optionally show CR, LF, TAB, SOH, NUL as visible markers.

Produce & drafts

A highlighted editor with key, partition and headers. Save drafts and send them in one click — PROD clusters ask first.

Errors that explain

Timeouts, SASL, TLS and authorization failures show their likely causes and retry automatically.

Query language

Find the one message you need.

Type a filter over the message value and the list narrows as you go. Nested fields, array indexes, null checks and negation all work.

# nested fields and logic
profile.age > 25 and username = "johndoe"

# arrays
languages contains "Python"
roles[0].roleName = Admin

# nulls and negation
phoneNumber is not null
not (isActive = true)

New · Test data

Send a thousand different messages in one click.

Drop functions like {{uuid}} or {{randomInt(1, 100)}} into the value, key or header values. Set a send count and every message is filled in anew — JSON validation still checks the result.

  • {{uuid}}
  • {{randomString(12)}}
  • {{randomInt(1, 1000)}}
  • {{randomDecimal(0, 100, 2)}}
  • {{randomBool}}
  • {{randomItem(red, green, blue)}}
  • {{index}}
  • {{timestamp}}
  • {{now}}

Install

Download, open, connect.

The Apache Kafka client and a Java runtime are bundled, so there is nothing else to install.

Windows.msi · -setup.exe macOS.dmg Linux.deb · .rpm · .AppImage

Upgrading from 1.x? Saved connections are imported on first start and their passwords move to the OS keychain.

Under the hood

Runs entirely on your machine.

Tauri · RustReact UIKeychain, local JSON files, file dialogs, live-tail events to the webview
line-delimited JSONstdin / stdout
Java 21 sidecarApache Kafka clientAdmin, consumer (assign), producer and live tail — one client pool per cluster

Build from source

Requires Node 22+, Rust (stable) and JDK 21+. Maven isn't needed.

npm install
npm run sidecar      # sidecar jar + jlink runtime
npm run tauri dev    # start the app
